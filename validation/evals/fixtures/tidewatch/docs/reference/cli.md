# Command line

| Command | What it does |
|---|---|
| `tidewatch add <path> --on-change CMD [--ignore GLOB]...` | add a watch and print its id |
| `tidewatch list` | list the watches: id, path, command |
| `tidewatch remove <id>` | remove a watch |
| `tidewatch run [--once]` | poll until interrupted, or once |
| `tidewatch check` | validate the settings and exit |
| `tidewatch version` | print the version |
