# Security policy

## Reporting a vulnerability

We take the security of `dogen` seriously. If you believe you have found a security
vulnerability, please report it to us privately — **do not** open a public GitHub issue,
discussion, or pull request for it.

Report security issues by email to **security@canonical.com**. Where possible, please
include:

- a description of the issue and the potential impact;
- the steps required to reproduce it;
- the affected version, commit, or component;
- any proof-of-concept or suggested remediation, if you have one.

You will receive an acknowledgement of your report, and we will keep you informed as we
investigate and work toward a fix. We ask that you give us a reasonable opportunity to
address the issue before any public disclosure.

## Scope

This policy covers the `dogen` source in this repository. Vulnerabilities in upstream
dependencies should be reported to their respective maintainers; if a dependency issue
affects `dogen` directly, you are welcome to let us know as well.
