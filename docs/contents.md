# crayon documentation

<!-- provenance: new page; the document list moved here from README.md (Further reading, Model evals) -->

Every document in this repository, in two groups. Start with `README.md` at the root of the
repository if you are new. The links on this page are plain paths, so they work in a browser.

## Using crayon

- [install.md](install.md): install by hand or with the script, every install choice,
  uninstall.
- [context.md](context.md): the context files that teach the skills your style, terms and
  structure, and how `/crayon-onboard` and `/crayon-fetch` produce them.
- [upgrade.md](upgrade.md): upgrade the tool, the skills and existing records.
- [hooks.md](hooks.md): what happens when a formatting hook rewrites a page.

## Under the hood

- [internals.md](internals.md): the glossary, the `crayon` commands the skills run, exit codes,
  and how the record lives in git.
- [compatibility.md](compatibility.md): the contract number and the minimum tool version that
  decide whether a skill and the tool work together.
- [contract.md](contract.md): the normative specification, frozen at the tag `contract-v1`.
- [architecture.md](architecture.md): the shape of crayon and its non-negotiables.
- [conventions.md](conventions.md): markup, the ledger, the commit seam and the documents.
- [development.md](development.md): tooling, tests and verification for contributors.
- [shellcheck.md](shellcheck.md): the shell lint policy.
- [evals.md](evals.md): the model evals, what they measure and how to read their results.
- [skills/README.md](../skills/README.md): the skill family contract and the routing table.
- [CHANGELOG.md](../CHANGELOG.md): the release record.
