# dogen documentation

`dogen` is an agentic documentation-drafting framework: it helps a Technical
Author draft review-ready documentation iteratively, with a human owning intent
and review at every step. This site is itself dogfood — drafted with `dogen` and
published with Sphinx + MyST to prove the loop's output is genuinely
Sphinx-publishable.
