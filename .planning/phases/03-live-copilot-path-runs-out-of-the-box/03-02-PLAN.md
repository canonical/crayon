Close all five Phase 3 gaps in the one code surface that owns them — the Copilot adapter (`provider.py`), its barrel (`__init__.py`), the provider seam (`mock_provider.select_provider`), and the thin CLI (`cli/main.py`) — verified against the Wave-0 fake-SDK harness from 03-01.

The five fixes (all locked decisions):
- **LIVE-01 (D-01/D-02/D-03):** retire `_DEFAULT_MODEL = "gpt-5"` → `"gpt-5-mini"`; add `--model` to `dogen draft`; thread it through `select_provider(name, *, model=None, effort=None)` (mock ignores, copilot forwards).
- **LIVE-02 (D-04):** pass `on_permission_request=PermissionHandler.approve_all` to `create_session` — safe by construction (only `grep`/`glob`/`view` available; write/exec/network unavailable AND on DENY).
- **LIVE-03 (D-05):** compute `reasoning_effort = self._effort.value if _is_gpt5_family(self._model) else None` and pass it unconditionally — the SDK omits it from the wire when `None` (RESEARCH Pattern 1, `client.py:1843`).
- **ERR-01 (D-06/D-07):** add `ModelRejectedError(RuntimeError)`; on a `-32603` + "is not available" `JsonRpcError`, raise it naming `self._model`.
- **ERR-02 (D-06/D-08):** catch `JsonRpcError` (non-model-rejection) and `ProcessExitedError` from `copilot._jsonrpc`, mapping them to `BackendUnavailableError`.
