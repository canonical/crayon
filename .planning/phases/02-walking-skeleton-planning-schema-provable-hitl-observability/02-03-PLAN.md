<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dogen → Copilot SDK/CLI | The adapter drives an external subprocess over JSON-RPC; the bounded toolset is the security boundary constraining what the agent can do |
| agent → source files | The agent reads operator-pointed source content; that content is untrusted input that flows into the draft (prompt injection) |
| SDK/CLI → host | An unbounded toolset would let the agent write/exec/reach the network on the host |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.3-01 | Elevation of Privilege | the agent's toolset | mitigate | Bounded read-only allowlist (`grep`/`glob`/`view`) via `available_tools` + a write/exec/network denylist via `excluded_tools` (D-28/SKEL-04); the exact built-in names are confirmed at the blocking checkpoint before the allowlist is locked — verify the allowlist actually constrains the agent (an acceptance criterion). |
| T-02.3-02 | Tampering / Information Disclosure | prompt injection from agent-read source content into the draft | mitigate | The toolset is read-only (no write/exec), so injected instructions cannot make the agent act outside drafting; the draft is human-reviewed before any commit (scope border); provenance records `context_origins` (what was actually read) for audit of the source→draft gap. |
| T-02.3-03 | Denial of Service / robustness | backend unavailable, CLI auto-update breaking transport (#1606) | mitigate | `get_status`/`get_auth_status` pre-check + `StopError`/connection-failure handling → `BackendUnavailableError` (clear message, nonzero exit, no crash — SKEL-05/D-27); the smoke test gates SDK/CLI version bumps. |
| T-02.3-04 | Information Disclosure | Copilot auth token | mitigate | The token is only used in the manual local smoke (env var per RESEARCH); CI uses `--provider mock` and never needs it (D-24); the token is never written to provenance/spans/logs. |
| T-02.3-SC | Tampering | the Copilot CLI runtime auto-updating to an unverified version | mitigate | Pin both SDK (`==1.0.2`) and the bundled CLI version (A2); the smoke test re-verifies on every bump; `T-{phase}-SC` package legitimacy dispositioned Approved in RESEARCH. |
</threat_model>
