## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator → CLI | Operator-supplied `<unit-id>` and `--intent`/`--audience` strings cross into filesystem path construction |
| CLI/adapter → filesystem | The store writes under the repo root; must never escape into `.planning/` or outside the intended `.dogen/`/`docs/` roots |
